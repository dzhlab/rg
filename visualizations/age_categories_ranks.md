## 1. Путь гимнастки: от новичка до чемпионки

```mermaid
graph TD
    Start[3-5 лет: Дошкольник] --> A[6-7 лет: Начинающая]

    B --> C[10-12 лет: Предюниор]
    C --> D[13-15 лет: Юниор]
    D --> E[16+ лет: Сеньор/Взрослая]

    A -.-> R1[III юн. разряд]
    B -.-> R2[II-I юн. разряд]
    B -.-> R3[III разряд]
    C -.-> R4[II-I разряд]
    C -.-> R5[КМС]
    D -.-> R6[МС]
    E -.-> R7[МСМК]
    E -.-> R8[ЗМС]

    style Start fill:#ffcccc

    style B fill:#ffffaa
    style C fill:#ccffaa
    style D fill:#aaffcc
    style E fill:#aaccff
    style R7 fill:#gold
```

## 5. Сравнение FIG и ВФХГ категорий

```mermaid
graph LR
    subgraph FIG[FIG Categories]
        F1[Pre-Junior<br/>до 13 лет]
        F2[Junior<br/>13-15 лет]
        F3[Senior<br/>16+ лет]
    end

    subgraph VFRG[ВФХГ Categories]
        V1[Предюниоры<br/>до 13 лет]
        V2[Юниоры<br/>13-15 лет]
        V3[Взрослые<br/>16+ лет]
        V4[+ Дополнительные<br/>возрастные группы]
        V5[+ Дуэты/Тройки]
        V6[+ Мужская РГ]
    end

    F1 -.Соответствует.-> V1
    F2 -.Соответствует.-> V2
    F3 -.Соответствует.-> V3

    style V4 fill:#ffcccc
    style V5 fill:#ffcccc
    style V6 fill:#ffcccc
```

## Структура композиции

### Классическая структура упражнения

```
┌─────────────────────────────────────────────────────┐
│           ВСТУПЛЕНИЕ (Intro)                        │
│           10-15 секунд                              │
│  • Выход на ковер                                   │
│  • Начальная поза                                   │
│  • Первый акцент                                    │
└─────────────────────────────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────────────┐
│           ЧАСТЬ 1 - Экспозиция                      │
│           20-25 секунд                              │
│  • 2-3 элемента DB                                  │
│  • 4-5 элементов DA                                 │
│  • Представление характера                          │
└─────────────────────────────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────────────┐
│           ЧАСТЬ 2 - Развитие                        │
│           25-30 секунд                              │
│  • 3-4 элемента DB (более сложные)                  │
│  • 5-6 элементов DA                                 │
│  • Кульминационные моменты                          │
│  • Элементы риска                                   │
└─────────────────────────────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────────────┐
│           ЧАСТЬ 3 - Кульминация                     │
│           15-20 секунд                              │
│  • 2-3 самых сложных DB                             │
│  • 4-5 элементов DA                                 │
│  • Высшая точка эмоционального накала               │
└─────────────────────────────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────────────┐
│           ФИНАЛ (Finale)                            │
│           10-15 секунд                              │
│  • Завершающая фраза                                │
│  • Финальная поза                                   │
│  • Яркое окончание                                  │
└─────────────────────────────────────────────────────┘

Общее время: 1:15 - 1:30 (75-90 секунд)
```

## Начинающий уровень (6-8 лет)

### Пример композиции с МЯЧОМ

**Музыка:** Детская, ритмичная (например, "Танец маленьких утят", "Барбарики")
**Длительность:** 1:00 - 1:15
**Цель:** III-II юношеский разряд

#### Композиция по тактам (4/4, темп 120 bpm)

```
ВСТУПЛЕНИЕ (такты 1-4, 8 секунд)
├─ Такт 1-2: Выход на ковер с мячом в руках
├─ Такт 3: Начальная поза (стоя, мяч над головой)
└─ Такт 4: Первый акцент - подброс мяча вверх

ЧАСТЬ 1 (такты 5-12, 16 секунд)
├─ Такты 5-6: Шаги по диагонали + отбивы мяча (DA 0.2)
├─ Такт 7: Прыжок согнувшись с мячом (DB 0.1)
├─ Такт 8: Перекат мяча по руке (DA 0.2)
├─ Такты 9-10: Волны с мячом в руках
├─ Такт 11: Подброс + ловля (DA 0.2)
└─ Такт 12: Переход к центру ковра

ЧАСТЬ 2 (такты 13-20, 16 секунд)
├─ Такты 13-14: Серия отбивов мяча в движении (DA 0.2)
├─ Такт 15: Равновесие passé с мячом (DB 0.1)
├─ Такт 16: Поворот на двух ногах 360° (DB 0.1)
├─ Такты 17-18: Перекат мяча по полу + проход (DA 0.2)
├─ Такт 19: Ловля мяча из переката
└─ Такт 20: Удержание мяча в красивой позе

ЧАСТЬ 3 (такты 21-26, 12 секунд)
├─ Такт 21: Бросок мяча средней высоты (DA 0.2)
├─ Такт 22: Прыжок шагом во время полета мяча (DB 0.1)
├─ Такт 23: Ловля мяча
├─ Такты 24-25: Шаги к финальной точке + отбивы
└─ Такт 26: Движение к финалу

ФИНАЛ (такты 27-30, 8 секунд)
├─ Такт 27-28: Перекат мяча вокруг тела (DA 0.2)
├─ Такт 29: Финальная поза в наклоне
└─ Такт 30: Удержание позы до конца музыки

ИТОГО:
DB: 4 элемента × 0.1 = 0.4
DA: 7 элементов × 0.2 = 1.4
D-score: ~1.8
```

#### Композиционная карта (план ковра)

```
        13m
    ┌─────────┐
    │    ↑    │
    │ ФИНАЛ   │
    │    5    │
13m │         │
    │  2   3  │
    │←──→ ←─→ │
    │  1   4  │
    │  ↓      │
    │СТАРТ    │
    └─────────┘

1 - Вступление (центр-низ)
2 - Часть 1 (диагональ влево-вверх)
3 - Часть 2 (центр)
4 - Часть 3 (диагональ вправо-вверх)
5 - Финал (центр-верх)
```

## Средний уровень (9-11 лет)

### Пример композиции с ОБРУЧЕМ

**Музыка:** "Испанский танец" или современная обработка фламенко
**Длительность:** 1:15 - 1:30
**Цель:** III-I разряд
**D-score цель:** 5.0 - 8.0

#### Подробная раскадровка

**[0:00-0:08] ВСТУПЛЕНИЕ - Фламенко-вход**

```
0:00-0:02  Стоя боком, обруч в руке
0:03-0:04  Резкий поворот головы + шаг (акцент музыки)
0:05-0:06  Вращение обруча на руке (DA 0.2)
0:07-0:08  Бросок обруча вверх (DA 0.3)
```

**[0:08-0:30] ЧАСТЬ 1 - Игра с обручем**

```
0:08-0:10  Ловля обруча + прыжок с поворотом 360° (DB 0.1)
0:11-0:13  Прокат обруча по полу (DA 0.2)
0:14-0:16  Пробежка за обручем + подхват
0:17-0:19  Вращение обруча на талии (DA 0.2)
0:20-0:22  Равновесие attitude с обручем (DB 0.2)
0:23-0:25  Проход через обруч (DA 0.2)
0:26-0:28  Серия вращений обруча на разных частях тела
0:29-0:30  Переход к кульминации
```

**[0:30-0:55] ЧАСТЬ 2 - Кульминация**

```
0:30-0:33  Бросок обруча высокий (3м) (DA 0.3)
0:34-0:36  Прыжок кольцом во время полета обруча (DB 0.3) [РИСК]
0:37-0:39  Ловля обруча + поворот 540° (DB 0.2)
0:40-0:43  Большой перекат обруча по телу (DA 0.3)
0:44-0:46  Шпагат стоя с обручем (DB 0.3)
0:47-0:50  Эшаппе обруча (освобождение и ловля) (DA 0.3)
0:51-0:53  Мельницы обручем в движении
0:54-0:55  Подготовка к финалу
```

**[0:55-1:15] ЧАСТЬ 3 - Финальный аккорд**

```
0:55-0:58  Серия прыжков с обручем (шагом + согнувшись) (DB 0.1×2)
0:59-1:02  Вращение обруча на руке в повороте 720° (DB 0.3)
1:03-1:06  Бросок обруча через спину (DA 0.3) [РИСК]
1:07-1:09  Ловля за спиной + выход в финальную позицию
1:10-1:12  Прокат обруча вокруг тела
1:13-1:15  Финальная поза (арабеск с обручем)
```

**Итого:**
- DB: 8 элементов (0.1-0.3) ≈ 1.6
- DA: 13 элементов (0.2-0.3) ≈ 3.5
- Риск: 2 элемента
- **D-score: ~5.1**

## Профессиональный уровень (15+ лет)

### Концепт-программа с БУЛАВАМИ

**Музыка:** "Болеро" Равеля (фрагмент, современная обработка)
**Длительность:** 1:25 - 1:30
**Цель:** МС, МСМК
**D-score цель:** 18.0 - 25.0+

#### Архитектура композиции

**КОНЦЕПЦИЯ:** Нарастающее напряжение "Болеро" - от шепота к крику

**ВСТУПЛЕНИЕ [0:00-0:10]** - Тишина перед бурей
```
Медленные, завораживающие движения
- Асимметричные мельницы булав (DA 0.2)
- Волны тела с булавами (DB 0.1)
- Перекаты булав по рукам (DA 0.2)
```

**ЧАСТЬ 1 [0:10-0:35]** - Первое crescendo
```
- Прыжок вертикальный 720° (DB 0.3)
- Малые броски двух булав асимметрично (DA 0.3)
- Равновесие attitude с поворотом 540° (DB 0.3)
- Постукивания булав в ритм (DA 0.2)
- Бросок одной булавы высоко (4м+) (DA 0.4) [РИСК]
- Поворот 1080° во время полета (DB 0.4)
- Ловля в повороте (DA 0.4) [РИСК]
```

**ЧАСТЬ 2 [0:35-1:05]** - Основное развитие
```
- Прыжок со сменой + поворот 720° (DB 0.4)
- Броски двух булав разной траектории (DA 0.4) [РИСК]
- Равновесие игла (DB 0.4)
- Ловли обеих булав (DA 0.4×2)
- Каскад бросков (серия) (DA 0.4)
- Фуэте 5 раз с мельницами (DB 0.4)
- Мельницы в прыжке кольцом (DB 0.4)
```

**ЧАСТЬ 3 [1:05-1:25]** - Кульминация и разрешение
```
- Высокие броски обеих булав вверх (DA 0.4×2) [РИСК]
- Двойной прыжок + поворот 1440° (DB 0.5+)
- Ловли за спиной без визуального контроля (DA 0.4×2)
- Поворот в шпагате 720° с булавами (DB 0.4)
- Серия ударов булав (ритмическая кульминация)
```

**ФИНАЛ [1:25-1:30]** - Апофеоз
```
- Финальная поза в затяжке с булавами
- Удержание до последнего аккорда
```

**Итого (приблизительно):**
- **DB:** 8 элементов высшей сложности = 3.0-3.5
- **DA:** 15 элементов = 5.0-6.0
- **Связки и бонусы:** +3.0-4.0
- **D-score:** ~11.0-13.5
- **+ Artistry, Execution** → Итого 30.0-40.0+

## Групповые композиции

### Пример: 5 гимнасток, 5 мячей

**Музыка:** Современная электронная музыка с ритмичным битом
**Длительность:** 2:15 - 2:30
**Концепция:** Синхронность и обмены

#### Структура (135-150 секунд)

**ВСТУПЛЕНИЕ [0:00-0:15]**
```
Формация: Линия
- Синхронный выход (5 гимнасток с мячами)
- Одновременные отбивы мячей (синхронно)
- Первая формация: звезда
```

**ЧАСТЬ 1 [0:15-0:45] - Синхронная работа**
```
Формация: Круг
- Одновременные прыжки с мячами (DB)
- Синхронные перекаты мячей (DA)
- Обмен 1: По кругу (каждая передает соседке)
```

**ЧАСТЬ 2 [0:45-1:15] - Асимметрия и обмены**
```
Формации: Диагонали, линии, квадрат
- Обмен 2: Крест-накрест
- Обмен 3: Через центр
- Коллаборация: 3 гимнастки держат мячи, 2 выполняют DB
- Обмен 4: Волна (последовательно)
```

**ЧАСТЬ 3 [1:15-1:45] - Кульминация**
```
Формация: Динамическая (постоянно меняется)
- Обмен 5: Высокие броски с обменом (РИСК)
- Синхронные повороты 720° с мячами (DB)
- Обмен 6: Все броски в центр одновременно
- Коллаборация: Сложная пирамида
```

**ФИНАЛ [1:45-2:15]**
```
Формация: Финальная (эффектная)
- Последний обмен (7-й минимум для запаса)
- Синхронная финальная поза
- Удержание до конца музыки
```

**Требования:**
- Минимум 6 обменов ✅ (у нас 7)
- Синхронность высокая
- Использование всего ковра
- Разнообразие формаций

## Музыкальный выбор

### Рекомендации по жанрам

| Предмет | Рекомендуемые стили | Примеры |
|---------|---------------------|---------|
| **Обруч** | Испанская музыка, фламенко, ритмичные мелодии | Кармен, Малагенья |
| **Мяч** | Легкая, игривая, джаз | "In the Mood", детские мелодии |
| **Булавы** | Энергичная, ритмичная, этническая | Болеро, африканские ритмы |
| **Лента** | Лирическая, вальсы, классика | Вальс цветов, Лебединое озеро |
| **Скакалка** | Быстрая, ритмичная, народная | Кадриль, тарантелла |

### Критерии выбора музыки

✅ **Соответствие предмету:** Характер музыки должен подчеркивать особенности предмета

✅ **Динамика:** Музыка должна иметь развитие (вступление, кульминацию, финал)

✅ **Темп:** Соответствовать уровню гимнастки (начинающие - медленнее, профи - быстрее)

✅ **Акценты:** Ярко выраженные акценты для элементов риска и кульминации

✅ **Оригинальность:** Не слишком избитая мелодия

✅ **Время:** Легко монтируется до нужной длительности (1:15-1:30 или 2:15-2:30)

## Чек-лист композиции

### Перед постановкой

- [ ] Музыка выбрана и смонтирована
- [ ] Определены ключевые элементы DB (8 макс.)
- [ ] Определены элементы DA (15 макс.)
- [ ] Распределены элементы риска (4 для сеньоров)
- [ ] Просчитан примерный D-score
- [ ] Учтены сильные стороны гимнастки

### Во время постановки

- [ ] Использована вся площадь ковра (13×13м)
- [ ] Есть смена уровней (партер, прыжки, стоя)
- [ ] Траектории разнообразны (диагонали, круги, линии)
- [ ] Элементы распределены равномерно по времени
- [ ] Музыкальные акценты подчеркнуты
- [ ] Есть вступление и яркий финал

### После постановки

- [ ] Программа укладывается в 1:15-1:30 (инд.) или 2:15-2:30 (группа)
- [ ] Все элементы засчитываются (технически правильны)
- [ ] Нет повторов одинаковых элементов (разнообразие)
- [ ] Программа соответствует музыке
- [ ] Костюм и музыка гармонируют
- [ ] Композиция рассказывает историю

## Советы хореографам и тренерам

### Золотые правила композиции

1. **Начинайте с музыки** - найдите музыку, которая вдохновляет
2. **Играйте на контрастах** - быстро/медленно, высоко/низко
3. **Не перегружайте** - лучше меньше, да лучше
4. **Используйте пространство** - весь ковер должен "жить"
5. **Рассказывайте историю** - у программы должна быть идея
6. **Подчеркивайте музыку** - движения = визуализация звука
7. **Будьте оригинальны** - избегайте клише
8. **Учитывайте возраст** - детям - игра, взрослым - драма

### Типичные ошибки

❌ Слишком много элементов в начале, пусто в конце
❌ Все сложные элементы подряд (нет передышки)
❌ Монотонные траектории (только по кругу или только по линии)
❌ Игнорирование музыкальных акцентов
❌ Слабое начало или финал
❌ Отсутствие кульминации
❌ Предмет "спит" (долго не используется)

# Шпаргалка судьи по художественной гимнастике / Judges Cheat Sheet

## ⚡ Быстрый справочник для судейства

---

## 📊 Структура судейской бригады

### Бригада D (Сложность) - 4 судьи
- **D1 и D2** - Первая подгруппа (оценивает DB - Body Difficulties)
- **D3 и D4** - Вторая подгруппа (оценивает DA - Apparatus Difficulties)

### Бригада E (Исполнение) - 6 судей
- Базовая оценка: **10.000**
- Вычитают сбавки за технические ошибки

### Бригада A (Артистизм) - 4 судьи
- Базовая оценка: **10.000**
- Оценивают выразительность и композицию

### Линейные судьи - 4 судьи
- Фиксируют выходы за пределы ковра

---

## ⏱️ Регламент времени

### Индивидуальные упражнения
- **Длительность:** 1:15 - 1:30 (75-90 секунд)
- **Сбавка за нарушение:** 0.05 за каждую полную секунду

### Групповые упражнения
- **Длительность:** 2:15 - 2:30 (135-150 секунд)
- **Сбавка за нарушение:** 0.05 за каждую полную секунду

### Несоответствие музыке
- **Сбавка:** 0.30 балла (если гимнастка закончила раньше/позже музыки)

---

## 🎯 Сложность (D-score)

### Требования к DB (Body Difficulties) - 2025-2028

| Параметр | Индивидуальные | Групповые |
|----------|----------------|-----------|
| Количество элементов DB | Максимум 8 | Зависит от композиции |
| Минимальная стоимость | 0.1 балла | 0.1 балла |
| Максимальная стоимость | 0.3+ балла | 0.3+ балла |
| Элементы риска (сеньоры) | 4 элемента | - |
| Элементы риска (юниоры) | 3 элемента | - |

**Примеры стоимости DB:**
- Прыжок согнувшись с поворотом 360° = **0.1**
- Вертикальный прыжок с прямыми ногами + поворот 720° = **0.3**
- Вертикальный прыжок с согнутой ногой (Passé) + поворот 360° = **0.1**

### Требования к DA (Apparatus Difficulties) - 2025-2028

| Параметр | Значение |
|----------|----------|
| Количество элементов DA | Максимум 15 |
| Минимальная стоимость | 0.2 балла |
| Максимальная стоимость | 0.4 балла |

**Стоимость по предметам:**

#### Обруч и Мяч:
- Большие перекаты = **0.3** (было 0.4 в 2022-2024)
- Ловля после высоких бросков = **0.4**
- Отбивы, вращения, проходы = **0.2**

#### Булавы:
- Минимальная база = **0.2**
- Максимальная база = **0.4**
- Броски двух булав = выше стоимость

#### Лента:
- Змейки, спирали = **0.2**
- Броски с ловлей = **0.3-0.4**
- Восьмерки = **0.2**

### ⚠️ Важные изменения 2025-2028:
- ❌ Критерий "под ногой" больше **НЕ применяется** для больших перекатов
- ❌ Маленькие броски **НЕ засчитываются** при выполнении базы "на полу"
- ❌ Маленькие броски и толчки **НЕ могут** выполняться во время BD для квалификации как DA

## ⚠️ Сбавки за исполнение (E-score)

### Градация ошибок

| Тип ошибки | Сбавка |
|------------|--------|
| Малая ошибка | 0.10 балла |
| Средняя ошибка | 0.30 - 0.50 балла |
| Грубая ошибка | 0.70 - 1.00 балл |

### Конкретные сбавки

#### Выход за границы ковра

| Нарушение | Сбавка |
|-----------|--------|
| Выход гимнастки за ковер | **0.20** (линейные судьи: 0.30) |
| Выход предмета за ковер | **0.20** (линейные судьи: 0.30) |
| Последовательный выход обеих булав | **0.30 + 0.30** = 0.60 |

#### Потеря предмета

| Ситуация | Сбавка |
|----------|--------|
| Потеря предмета в конце упражнения (последнее движение) | **0.50** |
| Потеря предмета во время упражнения | Зависит от расстояния |
| Предмет не пойман | 0.30 - 0.50 |

#### Технические ошибки

| Ошибка | Сбавка |
|--------|--------|
| Недостаточная амплитуда в волне тела | **0.10** |
| Малое отклонение от требуемой формы элемента | **0.10** |
| Неправильная техника выполнения элемента | **0.30 - 0.50** |
| Падение | **1.00** |
| Касание предмета телом (незапланированное) | **0.10 - 0.30** |
| Неуверенная ловля | **0.10 - 0.30** |

#### Дисциплинарные нарушения

| Нарушение | Сбавка |
|-----------|--------|
| Неправильный выход на ковер | **0.50** |
| Разминка в зале соревнований | **0.50** |
| Использование неподходящего предмета | **0.50** |
| Разговоры с другими | **0.50** |
| Музыка нетипичная для гимнастики | **0.50** |

#### Композиционные ошибки

| Нарушение | Сбавка |
|-----------|--------|
| Недостаточное использование площади ковра | **0.30** |
| Нет смены уровней | **0.30** |
| Монотонность траекторий движения | **0.10 - 0.30** |
| DA во время танцевальных шагов (с 2025) | **0.30** (DA засчитывается, S - нет) |

## 🎨 Артистизм (A-score)

### Критерии оценки

| Критерий | Что оценивается |
|----------|-----------------|
| **Музыкальность** | Соответствие движений музыке, акценты |
| **Выразительность** | Эмоциональная подача, мимика, пластика |
| **Композиция** | Оригинальность, разнообразие, целостность |
| **Использование пространства** | Покрытие всей площади ковра |
| **Связь предмета и движения** | Гармоничность работы с предметом |

### Базовая оценка: 10.000

Сбавки за отсутствие/недостаток критериев:
- Малое нарушение = 0.10
- Среднее нарушение = 0.30
- Грубое нарушение = 0.50

---

## 👥 Групповые упражнения - особенности

### Состав
- **5 гимнасток** обязательно

### Требования к обменам
- **Минимум 6 обменов** предметами между гимнастками

### Специфические сбавки

| Нарушение | Сбавка |
|-----------|--------|
| Рассинхрон в групповом элементе | 0.10 - 0.50 |
| Неудачный обмен предметом | 0.30 - 0.50 |
| Столкновение гимнасток | 0.30 - 0.50 |
| Неравномерное использование гимнасток | 0.30 |

## 📐 Технические требования к предметам

### Проверка перед соревнованиями

| Предмет | Размер/Вес (взрослые) | Размер/Вес (юниоры) |
|---------|----------------------|---------------------|
| **Обруч** | Ø 80-90 см, 300 г | Ø 70-90 см, 260 г |
| **Мяч** | Ø 18-20 см, 400 г мин | Ø 15-17 см |
| **Булавы** | 40-50 см, 150 г каждая | Меньше |
| **Лента** | 6 м (вкл. 1 м подшивки), 35 г | 5 м (вкл. 1 м подшивки), 30 г |
| **Скакалка** | По росту | По росту (только юниоры) |

### Обязательно:
- ✅ Логотип производителя
- ✅ **"FIG approved logo"**
- ✅ Соответствие цвета (отличается от костюма и ковра)

## 🚨 Типичные ошибки судей

### Субъективные факторы
- ❌ Предвзятость к своим ученикам
- ❌ Национальная/региональная предвзятость
- ❌ Оценка репутации, а не выступления

### Объективные сложности
- ⚠️ Судьи обрабатывают только ~80% спортивно-технической информации
- ⚠️ Сложность отслеживания всех элементов одновременно
- ⚠️ Быстрота исполнения упражнения

### Как избежать:
- 📹 Использование видеоповторов (где разрешено)
- 👥 Коллегиальное обсуждение спорных моментов
- 📊 Регулярное повышение квалификации
- 📝 Точное знание актуальных правил

- [ ] Следить за выходами за ковер
- [ ] Оценивать качество исполнения
- [ ] Отмечать композиционные требования

- [ ] Сверить оценки с другими судьями бригады
- [ ] Проверить расчеты
- [ ] Убедиться в правильности записи
- [ ] Быть готовым к объяснению оценки

## 📝 Формула итоговой оценки

```
ИТОГОВАЯ ОЦЕНКА = D + E + A - Штрафы

Где:
D = DB + DA (оценка сложности, открытая шкала)
E = 10.000 - сбавки (оценка исполнения)
A = 10.000 - сбавки (оценка артистизма)
Штрафы = время, дисциплина, музыка и др.
```

## 💡 Советы опытных судей

1. **Концентрация** - не отвлекаться на окружение
2. **Объективность** - судить выступление, а не репутацию
3. **Внимательность** - каждая деталь важна
4. **Знание правил** - постоянно обновлять знания
5. **Практика** - чем больше судишь, тем точнее оценки
6. **Командная работа** - доверять коллегам по бригаде
7. **Честность** - соблюдать этический кодекс судьи

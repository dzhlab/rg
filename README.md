## 📚 О проекте

Этот репозиторий содержит полную, структурированную информацию о правилах художественной гимнастики по международным стандартам FIG (Fédération Internationale de Gymnastique) и российским стандартам ВФХГ (Всероссийская Федерация Художественной Гимнастики).

**Цель проекта:** Предоставить спортсменам, тренерам, судьям и родителям централизованный источник актуальной информации о правилах, требованиях и стандартах художественной гимнастики.

## 🎯 Основные темы

### 1. Система оценивания

```
Итоговая оценка = D + E + A - Штрафы

где:
  D (Difficulty) = DB + DA
  E (Execution) = 10.000 - сбавки
  A (Artistry) = 10.000 - сбавки
```

- **D-score:** Сложность (открытая шкала, нет максимума)
- **E-score:** Исполнение (базовая 10.0, вычитаются сбавки)
- **A-score:** Артистизм (базовая 10.0, вычитаются сбавки)

### 2. Предметы

#### Для сеньоров (взрослых):
- 🔴 Обруч (Hoop) - Ø 80-90 см, 300 г
- 🔵 Мяч (Ball) - Ø 18-20 см, 400 г
- 🟣 Булавы (Clubs) - 40-50 см, 150 г каждая (2 шт)
- 🟡 Лента (Ribbon) - 6 м, 35 г

**Скакалка исключена из программы сеньоров с 2011 года**

### 3. Изменения 2025-2028

- ✅ DB: максимум **8 элементов** (было 9)
- ✅ DA: максимум **15 элементов** (было 20)
- ✅ Элементы риска: **4 для сеньоров, 3 для юниоров**
- ✅ Большие перекаты: **0.3 балла** (было 0.4)

### 4. Разряды в России (ЕВСК)

```
III юн. → II юн. → I юн. → III → II → I → КМС → МС → МСМК → ЗМС
                                                              ↑
                                                      Высшее звание
```

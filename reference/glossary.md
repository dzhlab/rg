## Система оценивания

| Русский | English | Français | Описание |
|---------|---------|----------|----------|
| **D-оценка** | D-score | Note D | Оценка сложности (Difficulty) |
| **E-оценка** | E-score | Note E | Оценка исполнения (Execution) |
| **A-оценка** | A-score | Note A | Оценка артистизма (Artistry) |
| **Итоговая оценка** | Final Score | Note Finale | D + E + A - штрафы |
| **DB** | Body Difficulty | Difficulté Corporelle | Сложность тела |
| **DA** | Apparatus Difficulty | Difficulté d'Engin | Сложность предмета |
| **Сбавка** | Deduction | Pénalité | Снижение оценки за ошибку |
| **Штраф** | Penalty | Pénalité | Фиксированное снижение (время, дисциплина) |
| **Технические ошибки** | Technical Faults | Fautes Techniques | Ошибки в E-оценке |
| **Артистические ошибки** | Artistic Faults | Fautes Artistiques | Ошибки в A-оценке |
| **Базовая оценка** | Base Score | Note de Base | 10.000 для E и A |
| **Открытая шкала** | Open-ended | Échelle Ouverte | D-оценка без максимума |

## Практическое использование

### Как пользоваться словарем:

1. **Для изучения правил FIG:**
   - Используйте английские и французские термины (официальные языки FIG)

2. **Для общения на международных соревнованиях:**
   - Запомните английские эквиваленты основных терминов

3. **Для работы с российскими документами:**
   - Знайте русские термины и сокращения

4. **Для переводов:**
   - Сверяйтесь с официальными документами FIG

## Примеры использования в контексте

### Пример 1: Описание элемента
**Русский:** "Поворот на 720° с аттитюд во время вращения ленты змейкой"
**English:** "720° pivot with attitude during ribbon snake"
**Français:** "Pirouette de 720° en attitude pendant le serpent au ruban"

### Пример 2: Оценка
**Русский:** "D = 12.5, E = 8.750, A = 8.900, итого = 30.150"
**English:** "D = 12.5, E = 8.750, A = 8.900, Total = 30.150"
**Français:** "D = 12.5, E = 8.750, A = 8.900, Total = 30.150"

## Body Difficulties (DB)

### Общие требования 2025-2028

- **Максимум в упражнении:** 8 элементов (было 9 в 2022-2024)
- **Минимальная стоимость:** 0.1 балла
- **Максимальная стоимость:** 0.3-0.6+ балла
- **Засчитываются:** Только технически правильно выполненные

---

## 1. Прыжки (Jumps)

### Базовые прыжки (0.1-0.2 балла)

| Элемент | Описание | Стоимость | Код |
|---------|----------|-----------|-----|
| **Вертикальный прыжок** | Прямые ноги, поворот 360° | 0.1 | - |
| **Прыжок согнувшись** | Ноги вперед, поворот 360° | 0.1 | - |
| **Прыжок в группировке** | Колени к груди, поворот 360° | 0.1 | - |
| **Прыжок с согнутой ногой (Passé)** | Одна нога согнута, поворот 360° | 0.1 | - |
| **Прыжок шагом** | Нога вперед, нога назад 180° | 0.1 | - |

### Средние прыжки (0.2-0.3 балла)

| Элемент | Описание | Стоимость | Требования |
|---------|----------|-----------|------------|
| **Вертикальный прыжок 540°** | Прямые ноги + поворот 540° | 0.2 | Высота, амплитуда |
| **Прыжок кольцом** | Спина назад, кольцо | 0.2-0.3 | Гибкость |
| **Прыжок казак** | Ноги врозь, одна вниз | 0.2 | Растяжка |
| **Прыжок шагом 180°** | Прямой шпагат в воздухе | 0.2 | Шпагат 180° |
| **Прыжок ножницы** | Смена ног в воздухе | 0.2 | Динамика |

### Сложные прыжки (0.3+ балла)

| Элемент | Описание | Стоимость | Требования |
|---------|----------|-----------|------------|
| **Вертикальный 720°** | Прямые ноги + поворот 720° | 0.3 | Высота, скорость вращения |
| **Прыжок со сменой** | Смена + поворот 540°+ | 0.3-0.4 | Динамика, поворот |
| **Прыжок двойное кольцо** | Обе ноги кольцом назад | 0.4+ | Экстремальная гибкость |
| **Прыжок с поворотом 1080°** | Любой прыжок + 3 оборота | 0.4+ | Мастерство |

## Элементы риска (Risk Elements)

### Требования 2025-2028

- **Сеньоры:** 4 элемента риска обязательно (было 5 макс.)
- **Юниоры:** 3 элемента риска обязательно

### Что считается элементом риска?

| Категория | Примеры |
|-----------|---------|
| **Высокие броски** | Высота 4м+ с ловлей за спиной/в повороте |
| **Динамические элементы** | Сальто, перевороты с предметом |
| **Ловли за телом** | Без визуального контроля |
| **Серии бросков** | Непрерывные броски без касания |
| **Комбинированные риски** | Бросок + акробатика + ловля |

## Изменения 2025-2028

### 📉 Снижения требований

| Параметр | 2022-2024 | 2025-2028 | Изменение |
|----------|-----------|-----------|-----------|
| **DB макс.** | 9 элементов | **8 элементов** | ⬇️ -1 |
| **DA макс.** | 20 элементов | **15 элементов** | ⬇️ -5 |
| **Риск макс.** | 5 элементов | **4 (сеньоры) / 3 (юниоры)** | ⬇️ -1/-2 |
| **Большие перекаты** | 0.4 балла | **0.3 балла** | ⬇️ -0.1 |

### ❌ Отмененные критерии

- **"Под ногой"** для больших перекатов - больше НЕ применяется
- **Маленькие броски** при выполнении базы "на полу" - НЕ засчитываются
- **Толчки/отбивы** во время BD для квалификации как DA - НЕ разрешены

### ✅ Новые правила 2025

- **DA во время танцевальных шагов:** DA будет засчитан, но S (шаг) НЕ засчитывается, сбавка 0.3

## Комбинирование DB и DA

### Принципы

1. **DB должен быть выполнен технически правильно** для засчитывания
2. **DA может выполняться одновременно с DB** (увеличивает сложность)
3. **Одновременное выполнение повышает ценность** композиции
4. **Но: сложность не суммируется автоматически**

### Примеры успешных комбинаций

| DB | DA | Эффект |
|----|----|----|
| Прыжок 720° | Бросок и ловля обруча | Высокая сложность + риск |
| Равновесие игла | Спирали ленты | Красота + техника |
| Поворот 1080° | Мельницы булав | Динамика + координация |
| Шпагат в воздухе | Перекат мяча по телу | Гибкость + мастерство |

## Практические советы

### Для спортсменов

✅ **Фокусируйтесь на качестве, а не количестве**
- Лучше 8 чистых DB, чем 10 с ошибками

✅ **Балансируйте сложность**
- Не все элементы должны быть максимальной сложности
- Сочетайте сложные и средние элементы

✅ **Отрабатывайте связки**
- Переходы между элементами должны быть плавными

✅ **Следите за обновлениями**
- Правила меняются каждый олимпийский цикл

### Для тренеров

✅ **Планируйте композицию заранее**
- 8 DB + 15 DA + 4 риска = стратегия

✅ **Учитывайте возраст и уровень**
- Не перегружайте начинающих

✅ **Изучайте брошюру FIG**
- Официальная брошюра содержит все DB с кодами

✅ **Анализируйте конкурентов**
- Смотрите выступления топ-гимнасток

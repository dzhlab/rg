## Квалификационные нормативы (баллы)

### Индивидуальные упражнения

#### Мастер Спорта Международного Класса (МСМК)

**Требования:**
- Участие в соревнованиях из Официального календара
- Определенные места на Чемпионатах мира, Европы, Олимпийских играх
- Или определенная сумма баллов на крупнейших международных соревнованиях

#### Мастер Спорта России (МС)

| Параметр | Требование |
|----------|------------|
| **Баллы** | 100.0 |
| **Упражнения** | 4 упражнения |
| **Состав** | 1 без предмета + 3 с предметами по выбору |
| **Минимальный возраст** | 14 лет (15 для официальных соревнований) |
| **Уровень соревнований** | Из Официального календара Минспорта |

#### Кандидат в Мастера Спорта (КМС)

| Параметр | Требование |
|----------|------------|
| **Баллы** | 60.0 |
| **Упражнения** | 4 упражнения |
| **Состав** | 1 без предмета + 3 с предметами по выбору |
| **Минимальный возраст** | 12 лет |
| **Уровень соревнований** | Региональные, всероссийские соревнования |

#### I спортивный разряд

| Параметр | Требование |
|----------|------------|
| **Баллы** | 46.0 |
| **Упражнения** | 3 упражнения |
| **Состав** | 1 без предмета + 2 с предметами по выбору |
| **Минимальный возраст** | 10 лет |
| **Уровень соревнований** | Региональные соревнования |

#### II спортивный разряд

| Параметр | Требование |
|----------|------------|
| **Баллы** | Согласно нормативам ЕВСК (меньше чем для I разряда) |
| **Упражнения** | 3 упражнения |
| **Состав** | 1 без предмета + 2 с предметами по выбору |
| **Минимальный возраст** | 9 лет |
| **Уровень соревнований** | Областные, городские соревнования |

#### III спортивный разряд

| Параметр | Требование |
|----------|------------|
| **Баллы** | 33.0 |
| **Упражнения** | 3 упражнения |
| **Состав** | 1 без предмета + 2 с предметами по выбору |
| **Минимальный возраст** | 8 лет |
| **Уровень соревнований** | Городские, районные соревнования |

#### Юношеские разряды (III, II, I)

| Параметр | Требование |
|----------|------------|
| **Баллы** | Согласно нормативам региональной федерации |
| **Упражнения** | 2-3 упражнения |
| **Состав** | С предметами согласно программе |
| **Минимальный возраст** | Без ограничений |
| **Уровень соревнований** | Клубные, районные, городские |

## Условия выполнения нормативов

### Уровень соревнований

| Разряд/Звание | Минимальный уровень соревнований |
|---------------|----------------------------------|
| **МСМК** | Олимпийские игры, Чемпионаты мира, Чемпионаты Европы |
| **МС** | Чемпионаты России, соревнования из Официального календара |
| **КМС** | Первенства России, Всероссийские соревнования |
| **I разряд** | Региональные, Всероссийские соревнования |
| **II разряд** | Областные, Межрегиональные соревнования |
| **III разряд** | Городские, Областные соревнования |
| **Юношеские** | Районные, Городские соревнования |

### Судейство

**Требования к судейской бригаде:**
- Для МС, МСМК - судейская бригада высшей квалификации
- Для КМС - судьи ВК (всероссийской категории)
- Для разрядов - судьи соответствующей категории
- Соблюдение правил FIG и ВФХГ

### Документация для присвоения

**Необходимые документы:**
1. Протокол соревнований (официальный)
2. Заявка от спортивной организации/клуба
3. Свидетельство о рождении или паспорт (подтверждение возраста)
4. Медицинская справка о допуске
5. Предыдущий разряд/звание (если есть)

## Процедура присвоения

### Шаг 1: Выполнение норматива
- Участие в соревновании соответствующего уровня
- Набор необходимой суммы баллов
- Соблюдение возрастных требований

### Шаг 2: Подача документов
- Тренер/спортивная организация подает заявку
- Приложение протокола соревнований
- Приложение копий документов

### Шаг 3: Рассмотрение
- Рассмотрение заявки соответствующей инстанцией
- Проверка выполнения всех требований

### Шаг 4: Присвоение
- Издание приказа о присвоении
- Внесение в реестр
- Выдача удостоверения (для званий)

## Особенности для художественной гимнастики

### Специфика вида спорта

- ✅ Один из немногих женских видов спорта (мужская РГ не признана FIG)
- ✅ Ранняя специализация (начало в 4-6 лет)
- ✅ Пик карьеры в 16-25 лет
- ✅ Высокие требования к гибкости и эстетике

### Особенности присвоения

- Оценка производится по сумме баллов за несколько упражнений
- Учитывается сложность (D), исполнение (E), артистизм (A)
- Требования периодически обновляются (каждый олимпийский цикл)
- Нормативы соответствуют международным стандартам FIG

## FAQ - Частые вопросы

**Q: Можно ли присвоить разряд, пропустив предыдущий?**
A: Да, можно. Главное - выполнить норматив на нужном уровне соревнований.

**Q: Сколько времени занимает присвоение?**
A: От нескольких недель до нескольких месяцев в зависимости от уровня.

**Q: Нужно ли подтверждать разряд?**
A: Спортивные разряды действуют до присвоения следующего. Спортивные звания (МС, МСМК, ЗМС) присваиваются пожизненно.

**Q: Можно ли лишить разряда/звания?**
A: В исключительных случаях (допинг, нарушение спортивной этики) возможно.

**Q: Что дает спортивный разряд/звание?**
A: Признание достижений, льготы при поступлении в вузы, возможность тренерской работы.

## Общие принципы ухода

### Основные правила

✅ **Регулярность** - ухаживайте за предметами после каждой тренировки
✅ **Бережность** - избегайте ударов и падений
✅ **Чистота** - держите предметы в чистоте
✅ **Правильное хранение** - храните в специальных чехлах
✅ **Своевременный ремонт** - не откладывайте мелкий ремонт

### Что влияет на срок службы предметов:

**Положительно:**
- Правильный уход
- Хранение в чехлах
- Аккуратное использование
- Своевременное обслуживание
- Хранение при комнатной температуре

**Отрицательно:**
- Небрежное обращение
- Хранение без чехлов
- Экстремальные температуры
- Влажность
- Прямые солнечные лучи
- Контакт с грязью и пылью

## Уход за обручем

### Характеристики

**Материалы:**
- Пластик (полиэтилен, полипропилен)
- Обмотка (скотч, клейкая лента, текстиль)

**Стандартные размеры (сеньоры):**
- Диаметр: 80-90 см (внутренний)
- Вес: 300 г (±10 г)
- Толщина: обычно 16-18 мм

### Ежедневный уход

**После каждой тренировки:**

1. **Очистка:**
   ```
   - Протереть влажной тряпкой
   - Удалить пот и следы рук
   - Убрать пыль и грязь
   - Высушить сухой тряпкой
   ```

2. **Проверка состояния:**
   ```
   - Проверить обмотку на отслоения
   - Осмотреть на наличие трещин
   - Проверить круглую форму
   - Убедиться в отсутствии деформаций
   ```

3. **Хранение:**
   ```
   - Положить в чехол
   - Хранить в горизонтальном положении
   - Избегать давления сверху
   ```

### Обмотка обруча

**Материалы для обмотки:**
- Специальная обмоточная лента (Chacott, Sasaki, Pastorelli)
- Цветной скотч (для тренировок)
- Декоративная лента (для соревнований)

**Как обмотать обруч:**

```
Подготовка:
1. Очистить обруч от старой обмотки
2. Удалить остатки клея (спирт/жидкость для снятия лака)
3. Высушить поверхность

Обмотка:
1. Начать с любого места
2. Натягивать ленту под углом 45°
3. Каждый виток перекрывает предыдущий на 3-5 мм
4. Равномерное натяжение по всей длине
5. Закрепить конец (прозрачный скотч)

Проверка:
- Обмотка гладкая, без бугров
- Нет отслоений
- Равномерная толщина
```

**Частота обмотки:**
- Тренировочные обручи: раз в 2-3 месяца
- Соревновательные: перед каждым соревнованием

### Восстановление формы

**Если обруч деформировался:**

**Метод 1: Горячая вода**
```
1. Нагреть воду до 70-80°C (не кипяток!)
2. Опустить обруч на 30-60 секунд
3. Аккуратно выровнять руками
4. Остудить в правильной форме
5. Проверить результат
```

**Метод 2: Фен**
```
1. Нагреть деформированный участок феном
2. Осторожно выправить
3. Остудить, держа в правильной форме
```

⚠️ **Внимание:** Не перегревайте обруч - может расплавиться!

### Типичные проблемы и решения

| Проблема | Причина | Решение |
|----------|---------|---------|
| Обмотка отслаивается | Плохое натяжение, старый клей | Переобмотать |
| Трещины | Падения, удары | Заменить обруч |
| Овальная форма | Неправильное хранение | Восстановить форму теплом |
| Липкая поверхность | Низкокачественный скотч | Очистить спиртом, переобмотать |

## Уход за мячом

### Характеристики

**Материалы:**
- Резина или синтетический каучук (ПВХ)

**Стандартные размеры (сеньоры):**
- Диаметр: 18-20 см
- Вес: 400 г (±20 г)
- Давление: регулируется индивидуально

### Ежедневный уход

**После каждой тренировки:**

1. **Очистка:**
   ```
   - Протереть влажной тряпкой
   - Удалить пыль и грязь
   - Высушить полностью
   - НЕ использовать агрессивные моющие средства
   ```

2. **Проверка давления:**
   ```
   - Проверить упругость
   - При необходимости подкачать/спустить
   - Использовать специальный насос
   ```

3. **Хранение:**
   ```
   - Положить в индивидуальный чехол
   - Хранить при комнатной температуре
   - Избегать прямых солнечных лучей
   ```

### Регулировка давления

**Как определить правильное давление:**

**Тест на отскок:**
```
1. Бросить мяч с высоты 1 метр
2. Оптимальный отскок: 50-70 см
3. Регулировать по ощущениям гимнастки
```

**Индивидуальная настройка:**
- Для бросков: чуть мягче (легче ловить)
- Для отбивов: чуть тверже (лучше отскок)
- Для прокатов: средняя жесткость

**Как накачать/спустить мяч:**

```
Инструменты:
- Специальная игла для мячей
- Насос с манометром
- Силиконовая смазка для иглы

Процедура накачивания:
1. Смазать иглу
2. Аккуратно вставить в клапан
3. Медленно накачать до нужного давления
4. Извлечь иглу
5. Проверить отскок

Спускание:
1. Вставить иглу
2. Слегка надавить на мяч
3. Выпустить лишний воздух
4. Извлечь иглу
```

⚠️ **Важно:** Не перекачивайте мяч - может лопнуть!

### Уход за поверхностью

**Цветные мячи (Chacott, Sasaki):**
- Не тереть сильно
- Избегать контакта с шероховатыми поверхностями
- Хранить отдельно от других предметов (краска может переноситься)

**Блестящие мячи (металлик):**
- Особенно бережно протирать
- Использовать только мягкую ткань
- Не допускать царапин

**Восстановление блеска:**
```
1. Протереть влажной тряпкой
2. Нанести каплю силиконовой смазки
3. Растереть мягкой тканью
4. Отполировать
```

### Типичные проблемы и решения

| Проблема | Причина | Решение |
|----------|---------|---------|
| Мяч спускается | Повреждение клапана | Проверить клапан, возможно заменить мяч |
| Потеря цвета | Износ, солнечный свет | Избегать солнца, заменить при сильном износе |
| Царапины | Контакт с шершавыми поверхностями | Профилактика, полировка |
| Липкая поверхность | Загрязнение | Очистить влажной тряпкой |
| Слишком мягкий/жесткий | Неправильное давление | Отрегулировать |

## Уход за булавами

### Характеристики

**Материалы:**
- Пластик или каучук
- Иногда с деревянной основой

**Стандартные размеры (сеньоры):**
- Длина: 40-50 см
- Вес каждой: 150 г (±10 г)
- **Важно:** Обе булавы должны быть одинакового веса!

### Ежедневный уход

**После каждой тренировки:**

1. **Очистка:**
   ```
   - Протереть влажной тряпкой
   - Особенно тщательно - ручки
   - Удалить остатки магнезии/канифоли
   - Высушить
   ```

2. **Проверка:**
   ```
   - Сравнить вес булав (на ощупь)
   - Проверить целостность
   - Убедиться в отсутствии трещин
   - Проверить баланс
   ```

3. **Хранение:**
   ```
   - Положить в чехол
   - Хранить вместе (пара)
   - Вертикальное или горизонтальное положение
   ```

### Обмотка ручек

**Зачем обматывать:**
- Улучшить хват
- Предотвратить скольжение
- Индивидуальная настройка веса

**Материалы:**
- Специальная обмоточная лента (как для обруча)
- Тейповая лента
- Цветная изолента (для тренировок)

**Как обмотать:**

```
1. Очистить ручку от старой обмотки
2. Начать от основания ручки
3. Обмотать плотно, виток к витку
4. Закрепить край скотчем
5. Проверить удобство хвата
6. Повторить для второй булавы
7. Убедиться, что вес обеих одинаков!
```

**Альтернатива - термоусадочная трубка:**
```
1. Надеть трубку на ручку
2. Нагреть феном
3. Трубка плотно обхватит ручку
4. Долговечное и удобное решение
```

### Балансировка булав

**Проверка баланса:**

```
Тест 1: Вращение на пальце
- Положить булаву на палец под головкой
- Должна балансировать горизонтально

Тест 2: Сравнение пары
- Вращать обе булавы одновременно
- Поведение должно быть идентичным
```

**Если баланс нарушен:**
- Проверить обмотку (может быть неравномерной)
- Проверить целостность булавы
- Возможно, нужна замена

### Типичные проблемы и решения

| Проблема | Причина | Решение |
|----------|---------|---------|
| Скользят из рук | Гладкие ручки, потные руки | Обмотать ручки, использовать магнезию |
| Разный вес | Разная обмотка | Переобмотать одинаково |
| Трещины на теле | Падения, удары | Заменить булавы |
| Сколы | Удары друг о друга | Аккуратнее при жонглировании |

## Уход за лентой

### Характеристики

**Материалы:**
- Сатин, вискоза или специальный синтетический материал
- Палочка: пластик, фиберглас, карбон

**Стандартные размеры (сеньоры):**
- Длина ленты: 6 метров (±5 см)
- Ширина: 5-6 см
- Вес ленты: минимум 35 г
- Палочка: 50-60 см, диаметр 1 см max

### Уход за лентой (тканью)

**После каждой тренировки:**

1. **Сворачивание:**
   ```
   - Аккуратно собрать ленту
   - Намотать на руку или палочку
   - НЕ комкать!
   - Положить в чехол
   ```

2. **Проверка:**
   ```
   - Осмотреть на наличие узлов
   - Проверить целостность ткани
   - Убедиться в отсутствии зацепок
   ```

**Стирка ленты:**

**Ручная стирка (рекомендуется):**
```
1. Теплая вода (30-40°C)
2. Мягкое моющее средство (жидкое мыло, детский шампунь)
3. Легкими движениями промыть
4. Тщательно прополоскать
5. НЕ выкручивать!
6. Повесить сушиться вертикально
```

**Машинная стирка (осторожно!):**
```
- Только деликатный режим
- 30°C
- Положить в мешок для стирки
- Отжим минимальный или без отжима
- Сушить естественным образом
```

⚠️ **Никогда не:**
- Не стирать в горячей воде (линяет, садится)
- Не отбеливать
- Не гладить утюгом
- Не сушить на батарее
- Не выкручивать

**Частота стирки:**
- Тренировочные ленты: раз в 1-2 недели
- Соревновательные: после каждого соревнования

**Восстановление формы:**

Если лента помялась или есть заломы:
```
1. Повесить вертикально
2. Слегка намочить проблемные места
3. Дать высохнуть под собственным весом
4. При необходимости - аккуратно прогладить с изнанки через тонкую ткань (низкая температура)
```

### Уход за палочкой

**Ежедневный уход:**

1. **Очистка:**
   ```
   - Протереть влажной тряпкой
   - Убрать остатки магнезии с ручки
   - Высушить
   ```

2. **Проверка:**
   ```
   - Проверить крепление карабина
   - Осмотреть на трещины
   - Проверить баланс
   - Убедиться в целостности ручки
   ```

**Крепление ленты к палочке:**

**Типы креплений:**
- Карабин (самое распространенное)
- Липучка
- Нейлоновая петля

**Как заменить карабин:**
```
1. Открутить старый карабин
2. Проверить резьбу на палочке
3. Вкрутить новый карабин
4. Затянуть плотно (но не переусердствуйте)
5. Проверить надежность
```

**Как прикрепить ленту:**
```
1. Продеть конец ленты через карабин
2. Сделать петлю
3. Зафиксировать швом (нитки в тон ленты)
4. Или использовать специальный зажим
```

### Распутывание узлов

**Профилактика:**
- Правильное сворачивание после тренировки
- Хранение в чехле
- Аккуратное использование

**Если образовался узел:**
```
1. НЕ тянуть с силой!
2. Найти начало узла
3. Аккуратно распутывать пальцами
4. При необходимости - использовать иголку
5. Разложить ленту полностью для проверки
```

### Типичные проблемы и решения

| Проблема | Причина | Решение |
|----------|---------|---------|
| Узлы на ленте | Неправильная работа | Аккуратно распутать |
| Лента не летит | Износ, тяжелая от грязи | Постирать или заменить |
| Лента липнет к полу | Статическое электричество | Антистатик, постирать |
| Разрыв ткани | Износ, зацепка | Заменить ленту |
| Потеря цвета | Стирка в горячей воде | Стирать только в холодной |
| Палочка треснула | Падение, износ | Заменить палочку |
| Карабин откручивается | Недостаточно затянут | Подтянуть, использовать фиксатор резьбы |

## Уход за скакалкой

*Примечание: Скакалка исключена из программы сеньоров с 2011 года, но используется в юношеских категориях и в России.*

### Характеристики

**Материалы:**
- Конопля, хлопок, нейлон, полиэстер

**Размер:**
- По росту гимнастки (стоя на скакалке, ручки достают до подмышек)

### Ежедневный уход

**После каждой тренировки:**

1. **Очистка:**
   ```
   - Протереть влажной тряпкой
   - Удалить пыль
   - Высушить
   ```

2. **Хранение:**
   ```
   - Аккуратно смотать
   - Избегать узлов
   - Хранить в чехле
   ```

**Стирка:**
- Ручная стирка в теплой воде
- Мягкое моющее средство
- Тщательное полоскание
- Сушка естественным образом

**Подготовка новой скакалки:**
```
1. Определить нужную длину
2. Обрезать лишнее
3. Завязать узлы на концах
4. Обработать концы (оплавить или зашить)
```

### Типичные проблемы и решения

| Проблема | Причина | Решение |
|----------|---------|---------|
| Скакалка путается | Неправильное хранение | Аккуратно сматывать |
| Износ концов | Трение о пол | Усилить узлы, обработать концы |
| Потеряла форму | Неправильное хранение | Замочить, высушить прямой |

## Уход за костюмами

### Ежедневный уход

**После каждой тренировки:**

1. **Проветривание:**
   ```
   - Вывесить на вешалку
   - Не складывать влажным
   - Проветрить 30-60 минут
   ```

2. **Проверка:**
   ```
   - Осмотреть швы
   - Проверить стразы и украшения
   - Убедиться в целостности
   ```

### Стирка костюмов

**Тренировочные купальники:**

**Ручная стирка (предпочтительно):**
```
1. Прохладная/теплая вода (до 30°C)
2. Мягкое моющее средство
3. Легкими движениями постирать
4. Тщательно прополоскать
5. НЕ выкручивать - отжать в полотенце
6. Сушить на вешалке
```

**Машинная стирка:**
```
- Деликатный режим
- Холодная вода (30°C)
- В мешке для стирки
- Без отжима или минимальный
- Сушка естественная
```

**Соревновательные костюмы:**

⚠️ **Только ручная стирка!**

```
1. Очень деликатно
2. Холодная вода
3. Специальное средство для деликатных тканей
4. Минимум механического воздействия
5. Бережное полоскание
6. Отжать в полотенце
7. Сушить горизонтально или на вешалке
```

**Уход за стразами и украшениями:**
- Не тереть
- Проверять крепление
- Подклеивать отпавшие стразы
- Хранить отдельно от других вещей

### Хранение костюмов

**Повседневное хранение:**
- На вешалке
- В чехле (для соревновательных)
- В сухом месте
- Избегать прямых солнечных лучей

**Длительное хранение (межсезонье):**
- Выстирать и высушить
- Упаковать в чехол
- Хранить в темном сухом месте
- Периодически проветривать

### Ремонт костюмов

**Мелкий ремонт:**
- Пришить отпавшие стразы (специальный клей для страз)
- Зашить небольшие разрывы
- Заменить резинки
- Починить застежки

**Когда обращаться к профессионалам:**
- Серьезные разрывы
- Замена основных элементов
- Переделка костюма
- Сложный декор

## Хранение предметов

### Организация хранения

**Дома:**

**Обручи:**
```
Вариант 1: Вертикально
- Специальная стойка
- Прислонить к стене (в чехле)

Вариант 2: Горизонтально
- На полке
- Не складывать друг на друга (максимум 2-3)
```

**Мячи:**
```
- В индивидуальных чехлах
- На полке или в корзине
- Не класть тяжести сверху
- Комнатная температура
```

**Булавы:**
```
- Парами в чехлах
- Вертикально или горизонтально
- В сухом месте
```

**Ленты:**
```
- Аккуратно свернутые
- В индивидуальных чехлах
- Палочка отдельно или с лентой
- В сухом месте
```

**В спортзале:**

**Общие принципы:**
- Каждый предмет в своем чехле
- Подписать (имя гимнастки)
- Специальный шкафчик или полка
- Порядок и чистота

### Условия хранения

**Температура:**
- Оптимально: 18-24°C
- Избегать: <5°C и >35°C
- Не хранить на морозе
- Не хранить на батареях

**Влажность:**
- Оптимально: 40-60%
- Избегать сырых помещений
- Проветривать хранилище

**Свет:**
- Избегать прямых солнечных лучей
- Цветные предметы выгорают
- Хранить в чехлах или закрытых шкафах

## Транспортировка

### Сумки и чехлы

**Типы сумок:**

**Для обруча:**
- Жесткий тубус (лучшая защита)
- Мягкий чехол (легче)
- Регулируемый ремень

**Для булав:**
- Чехол на 1-2 пары
- С карманами для аксессуаров
- Прочный материал

**Для мяча:**
- Индивидуальный чехол
- Мягкая подкладка
- Защита от давления

**Для ленты:**
- Отдельный чехол для ленты
- Отделение для палочки
- Защита от смятия

**Универсальная сумка:**
- Вмещает все предметы
- Отделения для каждого предмета
- Прочные лямки
- Дополнительные карманы

### Правила транспортировки

**В личном транспорте:**
```
✓ Закрепить сумки
✓ Избегать давления на предметы
✓ Не класть тяжести сверху
✓ Умеренная температура
```

**В общественном транспорте:**
```
✓ Держать сумки при себе
✓ Избегать давки
✓ Осторожно с обручами (хрупкие)
✓ Следить за лентами (не помять)
```

**Авиаперелеты:**

**Ручная кладь (рекомендуется):**
- Булавы - обычно разрешены
- Мяч - разрешен
- Лента - разрешена
- Обруч - может быть проблема (проверьте правила авиакомпании)

**Багаж:**
- Упаковать очень тщательно
- Жесткие чехлы
- Дополнительная защита (пузырчатая пленка)
- Подписать "Хрупкое"

⚠️ **Важно:** Уточните правила авиакомпании заранее!

## Ремонт предметов

### Что можно отремонтировать

**Обруч:**
- ✓ Переобмотать
- ✓ Восстановить форму (небольшие деформации)
- ✗ Трещины (только замена)

**Мяч:**
- ✓ Заклеить небольшой прокол (временно)
- ✗ Большие повреждения (замена)

**Булавы:**
- ✓ Переобмотать ручки
- ✗ Трещины в теле (замена)

**Лента:**
- ✓ Зашить небольшие разрывы
- ✓ Заменить карабин
- ✓ Переприкрепить к палочке
- ✗ Большие разрывы (замена ленты)

**Палочка:**
- ✓ Заменить карабин
- ✓ Обмотать ручку
- ✗ Трещины (замена палочки)

### Инструменты для ремонта

**Базовый набор:**
```
- Ножницы
- Изолента/скотч
- Иголка и нитки
- Клей (универсальный, для страз)
- Насос с иглой для мяча
- Запасные карабины
- Обмоточная лента
- Спирт для очистки
```

**Дополнительно:**
```
- Фен (для обруча)
- Силиконовая смазка
- Специальный клей для ремонта мячей
- Запасные резинки
- Фиксатор резьбы
```

## Признаки износа

### Когда пора менять предмет

**Обруч:**
- ✗ Видимые трещины
- ✗ Невосстановимая деформация
- ✗ Изменение веса (сильный износ пластика)
- ✗ Постоянные проблемы с обмоткой

**Мяч:**
- ✗ Пропускает воздух (не держит давление)
- ✗ Потеря упругости
- ✗ Значительная потеря цвета
- ✗ Деформация (не восстанавливает форму)

**Булавы:**
- ✗ Трещины в корпусе
- ✗ Изменение веса (разная пара)
- ✗ Потеря баланса (не восстанавливается)

**Лента:**
- ✗ Множественные разрывы
- ✗ Значительная потеря цвета
- ✗ Потеря "летучести" (тяжелая, не разворачивается)
- ✗ Усадка (значительно короче 6 метров)

**Палочка:**
- ✗ Трещины
- ✗ Искривление
- ✗ Поврежденная резьба для карабина

### Средний срок службы

**При правильном уходе:**

| Предмет | Тренировочный | Соревновательный |
|---------|--------------|------------------|
| **Обруч** | 1-2 года | 6-12 месяцев |
| **Мяч** | 1-2 года | 6-12 месяцев |
| **Булавы** | 2-3 года | 1-2 года |
| **Лента** | 6-12 месяцев | 3-6 месяцев |
| **Палочка** | 2-4 года | 1-2 года |

*Примечание: Срок службы зависит от интенсивности использования и уровня подготовки.*

## Чек-листы

### Ежедневный уход (после тренировки)

**Обруч:**
- [ ] Протереть влажной тряпкой
- [ ] Проверить обмотку
- [ ] Осмотреть на трещины
- [ ] Положить в чехол

**Мяч:**
- [ ] Протереть влажной тряпкой
- [ ] Проверить давление
- [ ] Положить в чехол

**Булавы:**
- [ ] Протереть, особенно ручки
- [ ] Проверить целостность
- [ ] Положить пару в чехол

**Лента:**
- [ ] Аккуратно смотать
- [ ] Проверить на узлы
- [ ] Положить в чехол
- [ ] Палочку протереть и убрать

### Еженедельная проверка

- [ ] Детальный осмотр всех предметов
- [ ] Проверка веса булав
- [ ] Проверка давления мяча
- [ ] Проверка обмотки обруча
- [ ] Проверка крепления ленты к палочке
- [ ] При необходимости - мелкий ремонт

### Ежемесячное обслуживание

- [ ] Генеральная чистка всех предметов
- [ ] Стирка лент (тренировочных)
- [ ] Переобмотка обруча (при необходимости)
- [ ] Переобмотка булав (при необходимости)
- [ ] Проверка состояния чехлов
- [ ] Ревизия запасных предметов

### Перед соревнованиями

**За 1 месяц:**
- [ ] Проверка состояния всех предметов
- [ ] Заказ новых (при необходимости)
- [ ] Подготовка запасного комплекта

**За 1 неделю:**
- [ ] Генеральная чистка всех предметов
- [ ] Стирка лент
- [ ] Обмотка обручей (новая)
- [ ] Проверка булав (вес, баланс)
- [ ] Регулировка мячей (давление)
- [ ] Упаковка запасного комплекта

**День соревнований:**
- [ ] Проверка основного комплекта
- [ ] Проверка запасного комплекта
- [ ] Все предметы чистые
- [ ] Все в рабочем состоянии
- [ ] Упаковано в сумки
